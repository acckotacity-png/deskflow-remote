deskflow remote
Windows host · Mobile & PC viewer · Beta

Your PC. Their browser.
One approved connection.

Control a Windows PC from another city, another network, or your phone. The PC owner starts DeskFlow and approves the connection. Your partner only needs a browser.

01 / On the PC being controlled

Share this computer

  1. Download and extract the Windows app.
  2. Open DeskFlowHost.exe and press Start internet session.
  3. Share its link and PIN. Press Allow when your partner connects.
Download for Windows

Windows 10/11, 64-bit. Portable ZIP: no Python or VPN setup. This beta is unsigned; review the source before running it.

02 / On the phone or other computer

Connect to a partner

Ask the PC owner for the session link shown in their DeskFlow app. Open it here, then enter their PIN and wait for approval.

For desktop icons, select Double click in the controller. A website tab alone cannot control Windows apps.

Hindi mein: Jiska PC chalana hai, woh Windows app khole → Start kare → link aur PIN bheje → aap link kholkar PIN daalein → woh Allow kare. Session band karne ke liye PC par STOP sharing dabayein.
What this version supports

Live primary-screen viewing, single/double/right click, selected keyboard keys, zoom, and vertical scroll. The host must stay open and the PC must stay awake and unlocked. Windows UAC/admin windows, drag-and-drop, full keyboard text entry, audio, and file transfer are not supported yet.

Internet sessions use a temporary Cloudflare Quick Tunnel. Links change when restarted and service availability is not guaranteed. Cloudflare relays the traffic; this is an attended beta, not an unattended service or a permanent-ID remote desktop product. The PC owner approves access, sessions expire after one hour, and Stop revokes access.
